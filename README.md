# Super Immersive Translate - 超级翻译

⚡ 一款功能强大的 Chrome 沉浸式双语翻译插件，对标沙拉翻译 + 沉浸式翻译，多引擎并行翻译，完全免费。

## ✨ 核心功能

### 🌐 全页双语翻译
- 一键翻译整个网页，原文与译文上下对照显示
- 智能段落识别，自动跳过代码块、图片、输入框等
- SPA 动态页面支持（MutationObserver 监听）
- 快捷键 `Alt+T` 快速切换

### 📖 划词翻译（沙拉翻译风格）
- 多引擎并行翻译，结果聚合展示
- 5 种触发模式可配置：
  - 🖱️ 图标模式 — 选中文字后出现 ST 图标，点击弹出面板
  - ⚡ 直接弹窗 — 选中即翻译
  - 👆 双击查词 — 双击单词弹出翻译
  - ⌨️ 快捷键 — 选中后按 `Alt+S` 翻译
  - 🚫 关闭 — 不启用划词翻译
- 面板可拖拽移动、📌 固定不消失
- 📋 一键复制翻译结果

### 🔊 单词朗读
- 划词面板内置 TTS 朗读按钮
- 使用浏览器原生语音合成，英语发音
- 朗读时图标动态反馈

### 🔍 面板内输入翻译
- 划词面板内置输入框
- 直接输入新单词或句子，回车即翻译
- 所有引擎并行返回结果

### ⭐ 单词收藏 & 学习
- 划词面板一键 ⭐ 收藏单词
- 自动保存所有引擎翻译结果、来源页面、时间戳
- 精美单词本学习页面（popup 底部 📖 入口）：
  - 📚 **单词列表** — 卡片式展示，搜索、标记已掌握/学习中、删除
  - 🎴 **卡片学习** — 翻转记忆卡片，键盘左右切换，空格翻转，随机模式
  - ✏️ **拼写测验** — 给翻译猜原词，实时计分
  - 📊 **学习统计** — 总数/已掌握/待学习/今日新增
- 支持 JSON 导入导出，方便备份迁移

## 🔧 翻译引擎

| 引擎 | 类型 | 说明 |
|------|------|------|
| Google 翻译 | 免费 | 默认引擎，无需配置 |
| Lingva Translate | 免费 | 开源 Google 翻译前端 |
| LibreTranslate | 免费 | 开源可自托管，支持自定义服务器 |
| MyMemory | 免费 | 翻译记忆库 |
| DeepL | 需 Key | 高质量翻译，有免费额度 |
| 自定义 API | 可选 | 接入任意翻译服务 |

## 📦 安装

1. 克隆仓库
```bash
git clone https://github.com/freedyc/super-immersive-translate.git
```

2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择项目文件夹

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt+T` | 切换全页翻译 |
| `Alt+S` | 翻译选中文字 |

```
├── background/

├── wordbook/                # 单词本学习页面
│   ├── index.html
│   ├── wordbook.css
│   └── wordbook.js
└── icons/                   # 图标
```
