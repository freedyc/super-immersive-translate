## 一、权限理由（直接粘进后台「隐私实践」页）

后台每一项权限都有一个单独的文本框，逐条对应粘贴。

### `storage`
保存用户的翻译设置、翻译历史、单词本与剪贴板记录。全部存于本地，不上传。

### `unlimitedStorage`
扩展内置离线音标词典（CMUdict，约 3.4MB）与词性词典（WordNet，约 1.2MB），
另需存储用户主动保存的剪贴板图片。默认 5MB 配额不足以容纳。

### `activeTab`
用户通过快捷键（Alt+T / Alt+S）或右键菜单触发时，对当前标签页执行翻译。

### `contextMenus`
提供右键菜单项：翻译此页面、翻译选中文本、在侧边栏打开、保存图片到剪贴板历史。

### `sidePanel`
将快捷翻译工作台以 Chrome 侧边栏形式打开，便于边浏览边翻译。

### `alarms`
用户开启 GitHub 跨设备同步后，定时触发后台同步。未开启同步时不使用。

### `host_permissions: <all_urls>`
本扩展的核心功能是在用户浏览的任意网页上提供划词翻译与整页双语对照，
因此需要在任意站点注入内容脚本，并向用户所选的翻译服务发起跨域请求。

请注意：扩展**不会**在后台扫描或上传页面内容。内容脚本仅在用户主动划词、
按下快捷键或点击翻译按钮时才处理文本，且只将被选中/待翻译的文本发送给
用户在设置中自行选定的翻译服务。用户可通过站点黑白名单禁用任意站点。

### 远程代码说明（若审核问及）
本扩展**不加载、不执行任何远程代码**，无 `eval` 与 `new Function`。
可选的 WebLLM 功能会从 huggingface.co 下载**模型权重数据**在本地推理，
下载的是数据文件而非可执行脚本，推理运行时（WASM）已随扩展一同打包。

## 二、数据用途声明（后台勾选项）

会收集：
- **个人通信内容** —— 剪贴板记录与翻译文本可能包含用户输入的内容
- **网站内容** —— 用户选中的待翻译文本、来源页面网址与标题
- **用户活动** —— 翻译历史、单词学习记录

三项声明均勾选：
- ☑ 不出售或转让给第三方（与核准用途无关的）
- ☑ 不将数据用于与核心功能无关的用途
- ☑ 不将数据用于判定信用度或放贷

隐私政策 URL：
`https://github.com/freedyc/super-immersive-translate/blob/main/docs/PRIVACY.md`

## 三、商品详情文案

**简短说明**（上限 132 字符）：
```
多引擎并行的沉浸式双语翻译：划词对比、整页对照、PDF/字幕/输入框翻译，内置 FSRS 单词本与剪贴板历史。
```

**详细说明**：
```
Super Immersive Translate 是一款功能完整的浏览器翻译工具。

【划词翻译】选中文字即可对比多个引擎的译文，支持发音、收藏单词、查看历史。
【整页双语】双语对照 / 译文替换 / 仅译文三种模式，支持鼠标悬停逐段翻译。
【字幕翻译】YouTube、Netflix、Bilibili、Coursera、Udemy、TED，以及 Zoom、
  Google Meet、Teams 的实时会议字幕。
【文档翻译】PDF、TXT、Markdown、HTML 文档翻译工作台。
【输入框翻译】在任意输入框中实时显示译文。
【单词本】基于 FSRS 间隔重复算法的学习闭环：四种题型、语境例句、
  内置离线音标与词性词典（无需联网、无需 AI）。
【剪贴板历史】自动记录复制过的文字与图片，随时取回。
  跨设备同步采用端到端加密，密码框内容不会被记录。
【多翻译引擎】Google、DeepL、OpenAI、Gemini、Claude、DeepSeek、
  MyMemory、Lingva、LibreTranslate、本地 Ollama、浏览器内 WebLLM。
  每个引擎的并发数可单独配置。

隐私：本扩展没有服务器，开发者收不到任何数据。所有内容默认只存在你的浏览器里。
完整说明见隐私政策。开源：github.com/freedyc/super-immersive-translate
```

**分类**：生产工具（Productivity）
**语言**：中文（简体）

## 六、审核可能追问的点

1. **为什么需要 `<all_urls>`** —— 见上方权限理由，强调「仅用户触发时工作」。
2. **WebLLM 是否为远程代码** —— 下载的是模型权重数据，运行时已打包，无 eval。
3. **OCR 会把图片传给第三方** —— 用的是 api.ocr.space 的公开演示 key，
   界面上已有明示，隐私政策中亦单列一节。
4. **剪贴板记录范围** —— 密码框、验证码框、脚本合成的复制事件均已排除，
   功能可在设置中关闭。
